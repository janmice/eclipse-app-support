使用說明

從第一筆訂閱開始，把現在的方案、真正付款與下一次扣款分別記清楚。

新增訂閱

  1. 在總覽或訂閱頁點選「＋」，選擇「手動新增」或「常用服務」。
  2. 填寫服務、方案、金額、幣別、付款週期與下一次扣款日期。
  3. 選擇「私人」或「工作」，再挑選方便辨識的圖示與分類。
  4. 其他帳號資訊、備註與連結可依需要填寫，確認後儲存。

月蝕不會自動讀取 Apple ID、銀行或信用卡中的訂閱；資料由你新增。

私人與工作用途

在總覽、訂閱、扣款手曆及支出分析切換「全部／私人／工作」。用途與服務分類是不同欄位，例如「工作」用途的「AI」服務。

修改訂閱目前的用途，只影響之後的新付款歸類與預估。每筆歷史付款保存自己的用途快照；需要更正某次付款時，請編輯該筆付款紀錄。

記錄真正付過的金額

開啟訂閱詳細頁，新增實際付款，核對金額、幣別、付款日期、對應帳期與付款用途。預估支出不會自動變成已付款紀錄。

現在的訂閱價格與歷史實付分開保存，因此修改目前價格不會改寫過去付款。

記下價格變化

編輯訂閱的目前價格時，確認新舊金額與價格生效日期，再儲存價格紀錄。若新增付款的金額與目前價格不同，可選擇只記錄付款，或同時確認更新目前價格。

詳細頁會保留價格歷史與漲跌幅，方便比較每次變化。

準備取消與確認取消

把續約決定改為「準備取消」，並在官方服務完成取消操作。確認取消後，可在月蝕更新狀態；已保存的付款與價格歷史仍會保留，未來扣款預估及提醒停止。

月蝕不會替你取消服務，也不會替你付款。

不同幣別與匯率

在設定中選擇基準幣與手動匯率。缺少匯率時，App 會標示尚未換算；它不代表該筆支出為零。

歷史付款使用當時保存的金額與匯率快照。修改目前的匯率，不會直接重算已保存的付款快照。

提醒與 Apple 行事曆

在設定中啟用裝置提醒，並允許 iOS 通知權限。可依訂閱選擇提前提醒天數；通知是否顯示也受裝置的通知與專注模式設定影響。

加入 Apple 行事曆時，月蝕會開啟 Apple 的事件編輯器，讓你確認保存或取消；App 不讀取所有行事曆內容。

資料與 iCloud

資料先保存於裝置。啟用 iCloud 同步的版本使用 Apple 的私人 CloudKit 資料庫；請以 App 設定頁顯示的帳號與同步狀態確認實際設定。離線時仍可使用本機帳本。

範例手札與你的正式帳本分開，不會把示範付款寫入正式資料。更多資料處理方式請看隱私政策。

回報問題

請至 GitHub Issues 提出問題或建議。可附上 App 版本、iOS 版本、操作步驟與預期結果。

GitHub Issues 是公開頁面。請先遮蔽截圖中的帳號、金額、付款資料與其他個人資訊，不要公開密碼或信用卡資料。
