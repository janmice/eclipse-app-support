기기 기록과 문자 인식

기기 이름, 모델, 일련번호, 보증, 사용자 지정 필드, 수리 이력, 선택한 사진은 기기에 저장됩니다. 문자 인식도 기기 안에서 이루어집니다. 회원 가입이 필요 없으며 광고, 사용 분석, 개발자가 운영하는 자동 동기화 기능이 없습니다. 구매 후 할 일, 수리 건과 연락처, 소모품 및 관리 이력도 기기에 저장됩니다.

카메라, 사진, 알림 및 구매

촬영할 때 카메라를 사용합니다. 시스템 사진 선택기는 선택한 사진만 앱에 제공합니다. 알림은 iPhone에서 발송하며 설정에서 끌 수 있습니다. Pro 구매와 복원은 Apple이 처리합니다. 앱은 검증된 거래 상태로 기능을 활성화하며 결제 카드 정보를 요청하지 않습니다.

공유, 백업 및 삭제

공유할 필드, 원본 사진과 대상을 직접 선택합니다. 내보낸 백업 파일에는 기기 정보와 사진이 포함되며 앱이 파일을 암호화하지 않습니다. 앱에서 기기와 첨부파일을 지울 수 있습니다. 다른 곳에 저장하거나 공유한 사본은 따로 관리해야 합니다. iCloud Drive와 기기 백업에는 해당 서비스의 정책이 적용됩니다.

웹사이트와 지원 문의

이 사이트는 GitHub Pages에서 제공합니다. GitHub는 사이트 운영과 보안을 위해 접속 정보를 처리할 수 있습니다. 공개 지원 게시물은 GitHub에서 처리하며 개발자는 문의 답변에 사용합니다. GitHub 개인정보 처리방침
