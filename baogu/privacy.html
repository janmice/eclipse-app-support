隱私政策

發布者 CHENYANG Chou · 2026 年 11 月 23 日生效

設備資料與辨識

設備名稱、型號、序號、各項保固、自訂欄位、維修紀錄與所選照片儲存在裝置。文字辨識在裝置上執行。App 無須註冊，不含廣告、分析服務或由開發者提供的自動同步。 購後待辦、送修案件、聯絡資料、耗材與保養紀錄也存放在裝置上。

相機、相簿、通知和購買

拍照使用相機。系統相簿選取器只會提供所選項目。到期提醒由 iPhone 發出，可在裝置設定關閉。Pro 購買和還原由 Apple 處理，App 使用已驗證的交易狀態開放功能，不索取付款卡資料。

分享、備份和刪除

你決定分享哪些欄位和原圖，以及接收對象。匯出的備份會包含設備與照片，檔案本身沒有加密。你可在 App 內刪除設備及附件；已分享或另存的副本需在各目的地處理。使用 iCloud Drive 或系統備份時，所選服務的政策另行適用。

網站與聯絡

本網站由 GitHub Pages 提供服務。GitHub 可能為網站運作與安全處理連線資訊。主動送出的公開支援留言由 GitHub 處理，開發者用來回覆問題。 GitHub 隱私聲明
