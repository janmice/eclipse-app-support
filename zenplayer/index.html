ZenPlayer隱私政策

ZenPlayer

免費的 iPhone、iPad 影音播放器。

播放影片

在「影片」頁匯入檔案，或透過「檔案」App 分享至 ZenPlayer。支援 MKV、WebM、MP4、MOV、M4V，並保存觀看位置。

字幕與播放

支援內嵌字幕與外掛 SRT、ASS、SSA。播放時可切換音軌、字幕、速度與畫面比例；支援子母畫面。iPhone Duo 半折時顯示上下分區控制，展開後以全螢幕播放。

NAS 與 Wi-Fi 傳檔

在「NAS」新增 SMB 伺服器，可直接播放或下載。Wi-Fi 傳檔需讓電腦與裝置連上同一個可信任網路，再於電腦開啟 App 顯示的網址並輸入驗證碼。Wi-Fi 傳檔使用區域網路 HTTP；離開傳檔頁面或進入背景後會關閉。

格式支援

支援 H.264、HEVC、AV1、VP8、VP9，以及 AAC、MP3、FLAC、AC-3、E-AC-3、Opus、Vorbis、ALAC、PCM。部分格式的支援依裝置而異；不提供 DTS、TrueHD 或 DRM 串流解鎖。

回報問題

請至 GitHub Issues 回報，標題註明 ZenPlayer，並提供版本、裝置及重現步驟。請勿公開密碼、NAS 位址或私人影片。

開源元件
