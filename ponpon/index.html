心願集章手帳

建立心願、設定任務、完成後蓋章。保存文字、照片與每一次行動紀錄。免費使用，最低支援 iOS 18。

建立心願卡

  1. 進入「探索心願」，從 16 種範本選一張，按「使用範本」；也可從首頁「＋」完全自訂。
  2. 設定心願名稱、插畫、印章、目標數量與獎勵，再編輯任務。
  3. 任務可設定每日、每週、自訂期間的次數限制，或設為只能完成一次的里程碑。
  4. 儲存後在「我的心願」開啟卡片。

蓋章與撤銷

選擇完成的任務，按「蓋章」並確認。每一個章都會保存正式紀錄；誤蓋時可在集章歷史中撤銷。每張卡依建立時保存的時區判斷每日與每週次數，週一為一週的開始。

日記與照片

在卡片詳細頁新增文字、心情與照片。透過 Apple 系統照片選擇器挑選要加入的照片；日記不會自動換成印章。

完成與收藏

集滿後可以選擇「完成心願」、「稍後實現」或「收藏這張卡」。完成與封存的卡片可在「回憶館」查看歷史。App 不會替你執行購買、轉職、搬家或其他重大決定。

備份與換機

在「設定」→「備份與還原」匯出包含照片的完整 JSON 備份，並保存至你選擇的位置。換機或重裝後，在相同頁面選擇備份檔還原。單一備份檔上限為 100 MB；請妥善保管，其中包含私人文字與照片。

第一版沒有 iCloud 同步、帳號、廣告、訂閱或通知提醒。刪除 App 可能同時刪除裝置內的資料，請先備份。

回報問題與隱私問題

請至 GitHub Issues 提出問題，標題註明 PON PON，並附上 App 版本、裝置、iOS 版本及操作步驟。此為開發者維護的支援管道。

Issues 是公開頁面，請勿貼出私人日記、照片、密碼或其他個人資料；截圖請先遮蔽個人內容。更多資料處理方式請見隱私政策。
