隱私政策

一點一點 PON PON! 不要求註冊開發者帳號，不含廣告或分析追蹤，也不會自行將心願、日記或照片上傳給開發者。

適用範圍

本政策說明一點一點 PON PON! 0.3.0 與本支援網站的資料處理方式。App 的開發者為 CHENYANG Chou。

保存在裝置的內容

心願卡、任務、集章歷史、日期與時區、日記、心情、選取的照片、明信片、提醒設定及偏好設定保存在 App 的本機儲存空間。開發者沒有遠端存取這些內容的功能。App 不設伺服器、分析 SDK、廣告識別碼或跨 App 追蹤。

照片與權限

只有你主動透過 Apple 系統照片選擇器挑選的照片會加入日記或明信片；App 不要求完整相簿或相機存取。照片會縮小後保存在裝置，以減少儲存空間。選擇「儲存到照片」時，App 會詢問僅新增照片的權限，用於儲存你製作的明信片。分享明信片的目的地由你自行選擇，不會自動公開或傳給開發者。

提醒與小工具

提醒需由你主動開啟並允許通知，由 Apple 本機通知服務排程，不使用開發者的推播伺服器。通知內容包含心願與任務名稱，可能顯示於鎖定畫面；你可以在系統設定調整預覽與通知權限。桌面小工具透過裝置上的共用儲存空間讀取心願進度與任務，不會傳給開發者。

iCloud 備份與還原

自動備份預設關閉。當你啟用或按「立即備份」時，心願、任務、集章歷史、日記、照片、提醒設定與已收藏明信片會儲存至你自己的 Apple 帳號所屬 iCloud Drive，使用你的 iCloud 空間。開發者沒有存取這些備份的功能，相關雲端服務由 Apple 提供。App 使用期間會在資料變更後安排備份，實際上傳由系統處理，可能受網路、空間與帳號狀態影響；請以「已上傳」為確認。每個裝置保留最近 5 份已上傳的自動備份，手動備份另行保留。

重裝 App 後，可在首次引導或設定中使用相同 Apple 帳號還原。完整還原會先保存一份本機回復備份，再取代現有資料；本機回復備份保留最近 5 份，刪除 App 時也會移除。備份功能不會即時合併不同裝置的資料。

檔案匯出與系統備份

你也可以手動匯出包含文字與照片的備份檔。儲存或分享目的地由你透過系統介面選擇；若選擇雲端磁碟或其他服務，其處理方式適用該服務的政策。備份檔案本身沒有額外密碼加密，請放在安全位置並避免公開分享。

Apple 的裝置備份可能依你的系統設定包含 App 資料，相關處理由 Apple 的服務與設定管理。

資料保留與移除

內容保留在你的裝置，直到你自行移除。放棄心願與撤銷印章會保留歷史。刪除日記會移除本機目前的該篇內容，但舊備份仍可能含有副本。刪除 App 可能同時移除本機資料；iCloud 備份不會隨 App 移除而刪除，關閉自動備份也不會刪除已存副本。你可在「檔案」App 的 iCloud Drive／一點一點／Backups 管理備份。自行匯出的檔案、其他服務的副本及系統備份，需在各自位置另行管理。沒有開發者帳號，因此不需要申請刪除帳號。

聯絡開發者

你可透過 GitHub Issues 提出功能或隱私問題。主動提供的留言由 GitHub 處理並供開發者查看；Issues 是公開頁面，請不要提交私人內容或其他敏感資料。

本網站

本網站使用 GitHub Pages 託管，沒有自行加入 JavaScript 分析工具、廣告、第三方字型或追蹤 Cookie。GitHub 可能為提供及保護網站服務處理連線資訊，詳見 GitHub 隱私聲明。
