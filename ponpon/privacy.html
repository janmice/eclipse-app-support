隱私政策

一點一點 PON PON! 不要求帳號，不含廣告或分析追蹤，也不會自行將心願、日記或照片上傳給開發者。

適用範圍

本政策說明一點一點 PON PON! 0.1.0 與本支援網站的資料處理方式。App 的開發者為 CHENYANG Chou。

保存在裝置的內容

心願卡、任務、集章歷史、日期與時區、日記、心情、選取的照片及偏好設定保存在 App 的本機儲存空間。開發者沒有遠端存取這些內容的功能。App 不設伺服器、分析 SDK、廣告識別碼或跨 App 追蹤。

照片與權限

只有你主動透過 Apple 系統照片選擇器挑選的照片會加入日記；App 不要求完整相簿或相機存取。照片會縮小後保存在裝置，以減少儲存空間。

匯出、還原與系統備份

只有在你選擇匯出時，App 才會建立包含文字與照片的備份檔。儲存或分享目的地由你透過系統介面選擇；若選擇雲端磁碟或其他服務，其處理方式適用該服務的政策。匯出檔案本身沒有額外密碼加密，請放在安全位置並避免公開分享。

App 不提供專屬的 iCloud 同步。Apple 的裝置備份可能依你的系統設定包含 App 資料，相關處理由 Apple 的服務與設定管理。

資料保留與移除

內容保留在你的裝置，直到你自行移除。封存卡片與撤銷印章會保留歷史，並非永久刪除。刪除 App 可能同時移除本機資料；自行匯出的檔案、分享至其他服務的副本及系統備份，需由你在對應位置另行管理。沒有帳號，因此不需要申請刪除帳號。

聯絡開發者

你可透過 GitHub Issues 提出功能或隱私問題。主動提供的留言由 GitHub 處理並供開發者查看；Issues 是公開頁面，請不要提交私人內容或其他敏感資料。

本網站

本網站使用 GitHub Pages 託管，沒有自行加入 JavaScript 分析工具、廣告、第三方字型或追蹤 Cookie。GitHub 可能為提供及保護網站服務處理連線資訊，詳見 GitHub 隱私聲明。

政策更新

如果未來版本的資料處理方式改變，會同步更新此頁的政策內容與日期。
