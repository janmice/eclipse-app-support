隱私政策

更新日期：2026 年 10 月 4 日

本政策說明「月蝕 Eclipse」App 與此支援網站如何處理資料。

你在 App 中輸入的資料

月蝕整理你自行輸入的訂閱與循環支出，包括服務與方案、金額與幣別、付款週期、日期、私人或工作用途、付款紀錄、價格歷史，以及你選擇填寫的帳號資訊、付款方式、連結與備註。

這些資料用於顯示帳本、計算支出預估與歷史實付、保存價格變化，以及安排你啟用的提醒。App 不會自動讀取 Apple ID 中其他 App 的訂閱，也不會登入銀行或信用卡帳號。

本機保存與 iCloud 同步

帳本先保存於你的裝置。啟用 iCloud 同步的版本會透過 Apple 的私人 CloudKit 資料庫，讓帳本在你的 iCloud 帳號中同步；實際是否啟用及同步狀態，以 App 的設定頁為準。

開發者不透過本 App 將帳本資料傳送至自建伺服器，不收集你的訂閱、付款或備註內容。iCloud 資料由 Apple 的服務處理，亦適用 Apple 隱私政策。

未登入 iCloud、離線或同步暫時無法使用時，App 仍以本機資料運作。App 不提供自建會員帳號。

裝置設定、通知與行事曆

  • 外觀與裝置提醒開關保存在 App 自己的裝置設定中。
  • 通知是可選功能。只有在你啟用提醒並允許 iOS 通知權限後，App 才安排本機通知。通知可能顯示服務名稱、金額、用途與日期；可在 iOS 設定中調整通知預覽或撤回權限。
  • 加入 Apple 行事曆時，App 開啟 Apple 的事件編輯器，由你確認保存或取消。App 不讀取所有行事曆，也不在背景替你新增事件。

追蹤、廣告與第三方分析

App 沒有廣告、跨 App 追蹤或第三方分析 SDK，不以帳本資料進行廣告分析或販售個人資料。

你選擇開啟的官方服務管理連結，會前往該服務或瀏覽器。該網站的資料處理方式依其自己的隱私政策。

資料管理

你可以在 App 中編輯自己新增的訂閱及付款紀錄。取消訂閱是一種帳本狀態，會保留過去的付款與價格歷史；它不是資料刪除，也不會替你在服務商完成取消。

若要清除裝置上的 App 資料，可透過 iOS 移除 App。移除 App 不代表 iCloud 中的資料也會一併刪除；如需管理 iCloud 中的 App 資料，請使用 Apple 的 iCloud 儲存空間管理功能。

支援網站與問題回報

此靜態網站由 GitHub Pages 提供服務，沒有加入外部字型、分析程式或追蹤程式。GitHub 可能依其政策處理網站存取所需的技術資料；請參考 GitHub 隱私聲明。

如果你透過 GitHub Issues 聯絡我們，你自行提交的內容會由 GitHub 處理，並顯示在公開問題頁面。請勿公開密碼、完整信用卡資訊、帳號、私人付款資料或未遮蔽的截圖。開發者會使用你提供的問題內容協助排查與回覆。

政策更新與聯絡

App 的資料處理方式若有調整，此頁會同步更新日期與內容。關於本政策的問題，請透過 GitHub Issues 聯絡。
